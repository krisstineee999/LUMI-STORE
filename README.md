
# LUMI STORE

LUMI STORE არის თანამედროვე, ადაპტირებადი ონლაინ ტანსაცმლისა და აქსესუარების მაღაზიის ვებპროექტი. ვებგვერდის მიზანია მომხმარებელს მისცეს შესაძლებლობა დაათვალიეროს პროდუქცია, მოძებნოს სასურველი ნივთი და დაამატოს ის კალათაში.

## გამოყენებული ტექნოლოგიები

- HTML5 — ვებგვერდის სტრუქტურა
- CSS3 — დიზაინი და სტილიზაცია
- Flexbox და CSS Grid — ელემენტების განლაგება
- JavaScript — ინტერაქტიული ფუნქციონალი
- Git — ვერსიების კონტროლი
- GitHub — პროექტის შენახვა და გამოქვეყნება

## პროექტის ფუნქციები

- პროდუქციის ჩვენება
- პროდუქციის კატეგორიების მიხედვით გაფილტვრა
- პროდუქციის ძებნა
- კალათაში ნივთების დამატება
- კალათაში რაოდენობის გაზრდა და შემცირება
- კალათიდან ნივთების წაშლა
- კალათის საერთო ღირებულების გამოთვლა
- მთავარი გვერდის ავტომატური სლაიდერი
- სლაიდერის ხელით მართვა
- მობილური ნავიგაციის მენიუ
- საკონტაქტო ფორმის დემო-ფუნქციონალი
- რესპონსიული დიზაინი

## პროექტის ფაილები

- index.html — ვებგვერდის სტრუქტურა
- style.css — დიზაინი და რესპონსიული სტილები
- script.js — JavaScript ფუნქციონალი
- README.md — პროექტის დოკუმენტაცია

## პროექტის გაშვება

1. ჩამოტვირთეთ ან დააკლონირეთ პროექტის რეპოზიტორია.
2. გახსენით პროექტის საქაღალდე კოდის რედაქტორში.
3. გახსენით index.html ბრაუზერში ან გამოიყენეთ Live Server გაფართოება.

## რესპონსიული დიზაინი

ვებგვერდი მორგებულია კომპიუტერის, პლანშეტისა და მობილური ტელეფონის ეკრანებზე CSS Media Queries-ის, Flexbox-ისა და Grid-ის გამოყენებით.
